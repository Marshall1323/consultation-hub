# Система онлайн-записи на консультации

Дипломный проект: веб-система для записи клиентов на консультации с автоматическим вычислением свободных временных слотов специалистов.

## Стек

- React, TypeScript, Vite
- Node.js, Express, TypeScript
- PostgreSQL, Prisma ORM
- JWT-аутентификация
- PostgreSQL 17

## Роли

- **Клиент** выбирает услугу, специалиста и доступное время, управляет своими записями.
- **Специалист** настраивает рабочее время, перерывы и исключения, просматривает записи.
- **Администратор** управляет пользователями, специалистами, услугами и всеми записями.

## Основная задача

Система должна формировать свободные слоты с учетом рабочего графика специалиста, длительности услуги, перерывов, исключений и существующих бронирований. Создание записи должно выполняться атомарно и не допускать двойного бронирования.

Подробные функциональные и нефункциональные требования находятся в [`docs/requirements.md`](docs/requirements.md).

## Запуск

При новой установке скопируйте `.env.example` в `apps/server/.env`.

1. Запустить PostgreSQL: `powershell -ExecutionPolicy Bypass -File scripts/start-database.ps1`.
2. Установить зависимости (только при первом запуске): `pnpm install`.
3. Выполнить миграции (после изменения схемы): `pnpm db:migrate`.
4. Запустить приложения: `pnpm dev`.

Остановить PostgreSQL можно командой `powershell -ExecutionPolicy Bypass -File scripts/stop-database.ps1`.

Frontend: http://localhost:5173  
Backend: http://localhost:4000/api/health
